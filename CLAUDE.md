# CLAUDE.md — Acta

Минималистичное macOS **menu-bar** приложение, которое **только записывает** онлайн-встречи
(Slack/Teams/Meet и любой источник звука): системный звук + микрофон. Транскрипция и саммари
**вне scope** (делаются отдельно локально через `mlx_whisper`). Полная спецификация — **`SPEC.md`**,
план — **`docs/plans/acta.md`**.

## Три обязательных свойства записи
1. **Потоковая запись на диск** (инкрементально, сегментами) — не буферизировать всю запись в памяти.
2. **Отказоустойчивость** — рестарт/краш не теряет записанное; на старте незавершённая запись
   автоматически восстанавливается.
3. **Самодиагностика** — если запись не пошла/встала, ошибка ловится сразу и лечится.

## Перед работой прочитать
- `SPEC.md` — решения, координаты API, подход к крэш-безопасности, критерии приёмки.
- Скиллы в `.claude/skills/`: `screencapturekit-audio`, `crash-safe-recording`,
  `swiftpm-macos-app-bundle`. **Опираться на них и на официальные доки, НЕ выдумывать API.**

## Команды
- Сборка: `bash Scripts/bundle.sh` (SwiftPM → `.app` + ad-hoc codesign; полного Xcode НЕТ)
- Компиляция: `swift build -c release`
- Тесты: `bash Scripts/test.sh` (реальный прогон через `ActaTestRunner`; падает с ненулевым кодом при первой ошибке). ⚠️ `swift test` под CLT-only ТОЛЬКО СОБИРАЕТ бандл (нет хост-утилиты `xctest`) — упавший тест даёт exit 0, поэтому для проверки не годится.
- Линтер: `bash Scripts/lint.sh` (обёртка над SwiftLint; ставит `DYLD_FRAMEWORK_PATH` для CLT-only — **raw `swiftlint` без Xcode падает**; конфиг — `.swiftlint.yml`)
- Запуск: `open Acta.app` (или `bash Scripts/run.sh`)

## Конвенции и правила
- Среда: только **Command Line Tools**, собирать через **SwiftPM** (не предполагать Xcode/xcodebuild).
- **Без внешних зависимостей** (транскрипции нет → WhisperKit не нужен).
- Приложение **не сэндбоксить** (личное использование); entitlements минимальные.
- Приватность: запись — **локально**, никуда не отправляется.
- **Крэш-безопасность важнее скорости:** писать сегментами, часто флашить, каждый сегмент — валидный
  файл. Незакрытый `AVAssetWriter`-файл после краша битый — отсюда сегментирование (см. скилл).
- **Никогда не показывать «recording», если данные реально не пишутся** — сначала самодиагностика.
- **Если застрял на SwiftUI/ScreenCaptureKit после нескольких попыток — свериться с доками (ссылки
  в скиллах) или запросить второе мнение у Codex.**
- Тесты: покрывать **чистую логику** (slug/front-matter, аргументы `ffmpeg`, логика выбора сегментов
  для восстановления, детектор «данные не текут»). Аудио/UI-рантайм тестируется вручную.

## Что НЕ проверяется автоматически (нужен живой тест человека)
- Выдача TCC-разрешений (Screen Recording, Microphone) — только через System Settings.
- Реальный захват звука — прогоном приложения вручную.
- Сценарий краша (`kill -9`) и авто-восстановление на следующем запуске — проверять вручную.
- Validation Commands (`swift build`/`swift test`/`lint`/`bundle`) проверяют только компиляцию/сборку/юнит-логику.
