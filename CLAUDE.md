# CLAUDE.md — Acta

Минималистичное macOS **menu-bar** приложение: запись онлайн-встреч (Slack/Teams/Meet и любой
источник звука) → локальная транскрипция → саммари через локальный `claude -p` → Markdown-архив
как рабочий контекст. Полная спецификация — в **`SPEC.md`**. План работ — **`docs/plans/acta.md`**.

## Перед работой прочитать
- `SPEC.md` — все зафиксированные решения, координаты API, критерии приёмки.
- Скиллы в `.claude/skills/` — по нишевым API (ScreenCaptureKit audio+mic, WhisperKit,
  SwiftPM-бандлинг без Xcode). **Опираться на них и на официальные доки, НЕ выдумывать API.**

## Команды
- Сборка: `bash Scripts/bundle.sh` (SwiftPM → `.app` + ad-hoc codesign; полного Xcode НЕТ).
- Компиляция: `swift build -c release`
- Тесты: `swift test`
- Запуск: `open Acta.app` (или `bash Scripts/run.sh`)

## Конвенции и правила
- Среда: только **Command Line Tools**, собирать через **SwiftPM** (не предполагать Xcode/xcodebuild).
- Приложение **не сэндбоксить** (личное использование); entitlements минимальные.
- Приватность: транскрипция и запись — **локально**. В облако уходит только шаг саммари через
  доверенный `claude -p` (осознанный выбор пользователя).
- Транскрипция: по умолчанию WhisperKit, **fallback — CLI `mlx_whisper`** (уже работает). Не
  застревать на WhisperKit — при трении переключаться на fallback.
- **Если застрял на SwiftUI/ScreenCaptureKit-проблеме после нескольких попыток — свериться с
  официальными доками (ссылки в скиллах) или запросить второе мнение у Codex.** (Практика из Радио-Т.)
- Тесты: покрывать **чистую логику** (front-matter/slug, построение промпта саммари, конструирование
  команды ffmpeg, парсинг сегментов транскрипта). Аудио/UI-рантайм тестируется вручную.

## Что НЕ проверяется автоматически (нужен живой тест человека)
- Выдача TCC-разрешений (Screen Recording, Microphone) — только через System Settings.
- Реальный захват звука и осмысленность транскрипта/саммари — прогоном приложения вручную.
- Validation Commands (`swift build`, `swift test`, `bash Scripts/bundle.sh`) проверяют только
  компиляцию/сборку/юнит-логику.
